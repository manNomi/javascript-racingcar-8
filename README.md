# javascript-racingcar-precourse

# 자바스크립트로 레이싱 게임을 만들자!!

## 도전해볼것

- 게임은 사람의 유흥을 위한것!! 재미있게 만들자
- 게임의 이스터에그를 넣어보자 - 특정입력에 한해서
- 사용자의 편의를 최대화 해보자! - 빈입력등 ,로 구분만 하면 돌아가게
  -> 메이플 랜덤 닉네임 생성기처럼
  -> 래퍼런스게임 : 핀볼 게임
- 테스트 입력 난수화를 적용해보자

## 기능 요구 사항

1. 입력

- [] 자동차의 이름 입력 형식([]string)
- [] 자동차 입력 : `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
- [] 몇번 이동할지 입력 형식([]number)
- [] 횟수 입력 : `시도할 횟수는 몇 회인가요?`

2. 출력

- [] 진행중 : `{car_name} : {"-" * repeat_count}`
- [] 단독우승자 : `최종 우승자 : {car_name}`
- [] 공동우승자 : `최종 우승자 : {car_name},{car_name}...`
- [] !로 시작하는 이스터에그
  !cat : 🐈
  !coin : 🚀

3. parser

- [] 자동차 입력을 , 기준으로 파싱

4. Car

- [] 자동차 (name,location,icon)
- [] name 지정 : 랜덤 닉네임 적용
  -> [] 랜덤 닉네임 생성기 1~5자 한국어,영어 허용
- [] move : car의 위치를 +1
  -> random 0~9 중 4이상인경우
- [] name이 !coin , !cat 일경우 특수 icon 적용

5. Game

- [] setCarGame : 이름 입력받음
- [] car 객체를 선언
- [] playGame : 1라운드 게임 시작

6. Controller (Flow)

- [] 1.자동차 이름 입력받기
- [] 2.자동차 이름 검증하기
- [] 3.게임 횟수 입력받기
- [] 4.게임 횟수 검증하기
- [] 5.게임 횟수만큼 gameplay , print 하기
- [] 6.결과 print 하기

## 검증 사항

자동차 이름

- [] 공백은 허용 -> 랜덤이름 적용
- [] 이름은 5자이하
- [] 동일한 이름 입력 불가
- [] 개수는 최대 10대

반복 횟수

- [] 양의정수만 입력가능
- [] 큰수 입력 방지 최대 10000

validate를 두가지로 나눠보자

1. controller에서의 validate (문법적 책임, string, number 등)
2. 도메인에서의 validate (도메인적 책임, 증복,특정글자수 등)

## 프로그래밍 요구사항

- depth는 최대 3까지 허용
- 3항 연산자 사용하지 말것
- 함수를 최대한 작게 만들것
- jest를 활용한 테스트 코드를 작성할것
