# javascript-racingcar-precourse

# 자바스크립트로 레이싱 게임을 만들자!!

## 도전해볼것

- 게임은 사람의 유흥을 위한것!! 재미있게 만들자
- 게임의 이스터에그를 넣어보자 - 특정입력에 한해서
- 사용자의 편의를 최대화 해보자! - 빈입력등 ,로 구분만 하면 돌아가게
  -> 메이플 랜덤 닉네임 생성기처럼
  -> 래퍼런스게임 : 핀볼 게임
- 테스트 입력 난수화를 적용해보자

## 기능 요구 사항

1. 입력

- [x] 자동차의 이름 입력 형식(string)
- [x] 자동차 입력 : `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
- [x] 몇번 이동할지 입력 형식(number)
- [x] 횟수 입력 : `시도할 횟수는 몇 회인가요?`

2. 출력

- [x] 진행중 : `{car_name} : {"-" * repeat_count}`
- [x] 단독우승자 : `최종 우승자 : {car_name}`
- [x] 공동우승자 : `최종 우승자 : {car_name},{car_name}...`
- [x] !rand 이스터에그로 랜덤 이름 + 랜덤 아이콘 생성
      !rand : 랜덤 이름 + 랜덤 아이콘(🐈, 🚀, - 중 하나)
      예시: "pobi,!rand,woni" → "pobi,Abuza🐈,woni"

3. parser

- [x] 자동차 입력을 , 기준으로 파싱

4. Car

- [x] 자동차 (name,location,icon)
- [x] name 지정 : 랜덤 닉네임 적용
      -> [x] 랜덤 닉네임 생성기 1~5자 영어 허용
      -> [x] 빈 이름("") 입력 시 랜덤 이름 생성
      -> [x] !rand 키워드 입력 시 랜덤 이름 생성
- [x] move : car의 위치를 +1
      -> random 0~9 중 4이상인경우
- [x] icon : 랜덤 아이콘 적용
      -> [x] !rand 또는 빈 이름일 경우 랜덤 아이콘 (🐈, 🚀, -)
      -> [x] 일반 이름일 경우 기본 아이콘 (-)

5. Game

- [x] 자동차 이름 입력받아 Car 객체 생성
- [x] play : 게임 진행 및 결과 반환 (배열)
- [x] getWinners : 우승자 계산 및 반환

6. Controller (App)

- [x] 1.자동차 이름 입력받기
- [x] 2.게임 횟수 입력받기
- [x] 3.Game 객체 생성
- [x] 4.게임 진행 (play)
- [x] 5.결과 출력 (라운드별 진행상황)
- [x] 6.우승자 출력

## 검증 사항

자동차 이름

- [x] 빈 이름("") 허용 -> 랜덤이름 적용
- [x] !rand 키워드 -> 랜덤이름 + 랜덤아이콘 적용
- [x] 이름은 5자이하 (!rand는 예외)
- [x] 동일한 이름 입력 불가
- [x] 빈 이름 및 공백만 있는 이름 자동 필터링
      예시: "pobi,,woni" → ["pobi", "woni"]
      예시: "pobi, ,woni" → ["pobi", "woni"]
- [ ] 개수는 최대 10대

반복 횟수

- [x] 양의정수만 입력가능
- [ ] 큰수 입력 방지 최대 10000

검증 설계

1. [x] Game에서의 validate (입력값 검증: 빈값, 숫자, 정수, 양수)
2. [x] Car에서의 validate (도메인 검증: 이름 길이)
3. [x] validate 유틸 함수 분리 (재사용)
